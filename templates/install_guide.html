安装指南

步骤 1：下载技能包

返回 主页，找到需要的 Skill。

点击版本号（如 v1.0.0）下载 ZIP 文件。

步骤 2：解压 ZIP 文件

将下载的 ZIP 文件解压到任意目录。

步骤 3：复制到 Claude Skills 目录

将解压后的技能目录复制到 Claude Code Skills 目录：

默认 Skills 目录位置：

  • Windows: %USERPROFILE%\.claude\skills\
  • macOS / Linux: ~/.claude/skills/

Windows 示例：

xcopy /E /I "skill-name" "%USERPROFILE%\.claude\skills\skill-name"

macOS / Linux 示例：

cp -r skill-name ~/.claude/skills/

步骤 4：重启 Claude Code

安装完成后，重启 Claude Code 或在侧边栏刷新 Skills，新的 Skill 将会自动加载。

设置环境变量（可选）

如果你的 Claude Code Skills 目录不在默认位置，可以设置环境变量：

Windows：

setx CLAUDE_SKILLS_PATH "C:\path\to\your\skills"

macOS / Linux：

# 添加到 ~/.bashrc 或 ~/.zshrc
export CLAUDE_SKILLS_PATH="/path/to/your/skills"

常见问题

Skill 安装后不生效？

  1. 确认目录已正确复制到 Skills 目录
  2. 确认目录中包含 package.json
  3. 重启 Claude Code 或重新加载窗口

如何更新 Skill？

下载新版本的 ZIP 文件，解压后覆盖原目录即可。

如何卸载 Skill？

直接删除对应的 Skill 目录即可。

注意： 技能包是原始用户上传的文件，请确保来源可信。
