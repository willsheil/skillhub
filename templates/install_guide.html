安装指南
新功能：现在所有下载的技能包都自带一键安装脚本！解压后直接运行脚本即可自动安装。

一键安装（推荐）

步骤 1：下载技能包

返回 主页，找到需要的 Skill。

点击版本号（如 v1.0.0）下载 ZIP 文件，或使用"批量下载"功能一次性下载多个 Skills。

步骤 2：一键安装

解压下载的 ZIP 文件，根据你的系统运行对应脚本：

Windows：

# 双击运行
install.bat

macOS / Linux：

# 在终端中运行
chmod +x install.sh
./install.sh

安装脚本会自动：

  • ✓ 检测 Claude Code Skills 目录
  • ✓ 处理已存在技能的冲突（覆盖/跳过/备份）
  • ✓ 将技能安装到正确位置

步骤 3：重启 Claude Code

安装完成后，重启 Claude Code 或在侧边栏刷新 Skills，新的 Skill 将会自动加载。

批量安装多个技能

在主页选择多个技能后点击"批量下载"，解压后会得到：

  • install-all.bat / install-all.sh - 一键安装所有技能
  • 每个技能的独立目录（仅包含技能文件）

Windows 批量安装：

install-all.bat

macOS / Linux 批量安装：

chmod +x install-all.sh
./install-all.sh

批量安装脚本会自动处理所有技能目录，支持冲突处理（覆盖/跳过/备份）。

设置环境变量（可选）

如果你的 Claude Code Skills 目录不在默认位置，可以设置环境变量：

Windows：

setx CLAUDE_SKILLS_PATH "C:\path\to\your\skills"

macOS / Linux：

# 添加到 ~/.bashrc 或 ~/.zshrc
export CLAUDE_SKILLS_PATH="/path/to/your/skills"

设置后，安装脚本会自动使用此路径，无需手动输入。

手动安装（备用）

如果一键安装脚本无法正常工作，可以手动安装：

步骤 1：解压 ZIP 文件

步骤 2：将技能目录复制到 Claude Code Skills 目录

默认 Skills 目录位置：

  • Windows: %USERPROFILE%\.claude\skills\
  • macOS / Linux: ~/.claude/skills/

步骤 3：重启 Claude Code

注意事项

重要：
  • 一键安装脚本会自动检测 Claude Code Skills 目录，检测失败时会提示手动输入
  • 如果技能已存在，脚本会提示选择：覆盖安装 / 跳过安装 / 备份旧版本
  • ZIP 文件内部包含 install.bat 和 install.sh，与技能文件在一起
  • 如果 Skill 不生效，尝试重启 Claude Code

常见问题

Skill 安装后不生效？

  1. 检查解压路径是否正确
  2. 确认目录中包含 package.json
  3. 重启 Claude Code 或重新加载窗口

如何更新 Skill？

下载新版本的 ZIP 文件，直接覆盖解压即可。

如何卸载 Skill？

直接删除对应的 Skill 目录即可。
