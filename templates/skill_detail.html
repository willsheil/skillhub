安装方式

将此提示发送给你的 Agent 以安装该技能：

📄 Agent prompt
从我的私有 Git 仓库安装技能： 仓库地址：{{ gitea_repo_url }} 技能目录：{{ skill_dir }} 请克隆仓库，找到该技能并安装到 .claude/skills

💡 提示：将上面的 Prompt 发送给 Claude Code 或其他 AI Agent，它会自动完成安装。

手动安装步骤：

方式一：下载 ZIP 包

在 Claude Code 上安装

  1. 下载 Skill 包
  2. 将其解压到全局 Skills 目录
  3. 重新加载 Claude Code 窗口以应用

目录结构：

~/.claude/skills/{{ skill_name }}
├── SKILL.md
└── ... (来自此包的其他资源文件)

在 Codex 上安装

  1. 下载 Skill 包
  2. 将其解压到全局 Skills 目录
  3. 重启 Codex 即可使用

目录结构：

~/.codex/skills/{{ skill_name }}
├── SKILL.md
└── ... (来自此包的其他资源文件)

在 Cursor 上安装

  1. 下载 Skill 包
  2. 将其解压到工作区级别的 Skills 目录
  3. 重新加载 Cursor 窗口以应用

目录结构：

~/.cursor/skills/{{ skill_name }}
├── SKILL.md
└── ... (来自此包的其他资源文件)

在 VS Code 上安装

  1. 下载 Skill 包

  3. 重新加载 VS Code 窗口以应用

目录结构：

~/.vscode/skills/{{ skill_name }}
├── SKILL.md
└── ... (来自此包的其他资源文件)

在 Cline 上安装

方式二：npx skills 安装

使用 npx skills 命令安装：

npx -y skills add {{ request_url }} --skill {{ skill_name }}

方式三：Marketplace 命令

使用 marketplace 命令安装：

/plugin marketplace add http://127.0.0.1:28000/admin/skills__hub.git
/plugin install {{ skill_name }}
