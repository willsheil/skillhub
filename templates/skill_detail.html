手动安装步骤：

方式一：下载 ZIP 包

在 Claude Code 上安装

  1. 点击下方下载 ZIP 包按钮
  2. 将压缩包解压到 ~/.claude/skills/{{ skill_name }} 目录
  3. 重新加载 Claude Code 窗口以应用

目标目录结构：

~/.claude/skills/{{ skill_name }}
├── SKILL.md
└── ... (其他资源文件)

在 Codex 上安装

  1. 点击下方下载 ZIP 包按钮
  2. 将压缩包解压到 ~/.codex/skills/{{ skill_name }} 目录
  3. 重启 Codex 即可使用

目标目录结构：

└── ... (其他资源文件)

方式二：npx skills 安装

选择 Agent 类型：

安装到 Claude Code (~/.claude/skills/)：

npx skills add {{ request_url }}{{ download_url }} --agent claude

安装到 Codex (~/.codex/skills/)：

npx skills add {{ request_url }}{{ download_url }} --agent codex

安装到 Cursor (~/.cursor/skills/)：

npx skills add {{ request_url }}{{ download_url }} --agent cursor

安装到 Cline (~/.cline/skills/)：

npx skills add {{ request_url }}{{ download_url }} --agent cline

安装到 VS Code (~/.vscode/skills/)：

npx skills add {{ request_url }}{{ download_url }} --agent vscode
