## 用户使用指南

### 1. 系统登录

#### 1.1 获取账号

首次使用需要联系管理员开通账号，您需要提供：
- 工号（Employee ID）：格式为字母+8位数字（如：w00000001）
- 联系方式

管理员会为您分配：
- 初始 API Key

#### 1.2 登录系统

1. 访问系统地址：`http://your-domain:28000`
2. 点击右上角"登录"按钮
3. 输入您的工号和 API Key
4. 点击"登录"完成认证

**登录界面示例**:
```
┌─────────────────────────────┐
│      SkillHub 技能注册表     │
│                             │
│  工号: [_______________]     │
│                             │
│  API Key: [_______________]  │
│                             │
│      [ 登录 ]  [ 重置 ]      │
└─────────────────────────────┘
```

#### 1.3 修改 API Key

建议首次登录后修改您的 API Key：

1. 登录后点击右上角用户名
2. 选择"个人设置"
3. 点击"修改 API Key"
4. 输入新 API Key 并确认

> **安全提示**: 请妥善保管您的 API Key，不要与他人分享。

### 3. 上传技能

#### 3.1 准备技能文件

在上传前，请确保您的技能文件符合以下格式：

**必需文件结构**:
```
your-skill.zip
├── SKILL.md        # 技能元数据（必需，使用YAML frontmatter格式）
└── 其他技能文件...
```

**SKILL.md 格式示例**（YAML Frontmatter）:
```yaml
---
name: Code Review Assistant
description: 一个智能代码审查助手，帮助发现代码中的潜在问题和改进点
metadata:
  version: 1.0.0
  author: w00000001
  tags: code-review, python, quality
  category: 代码质量
license: MIT
compatibility: Claude Code 1.0+
allowed-tools: bash, grep, read
---

# Code Review Assistant

一个智能代码审查助手，帮助发现代码中的潜在问题和改进点。

## 功能说明

- 自动检测代码规范问题
- 提供优化建议
- 生成审查报告

## 使用方法

在 Claude Code 中调用此技能来审查代码...
```

#### 3.2 上传步骤

1. 登录系统
2. 点击顶部菜单"上传技能"
3. 选择技能 ZIP 文件
4. （可选）填写来源类型
5. 点击"上传"按钮

**上传界面**:
```
┌───────────────────────────────────────┐
│ 上传新技能                            │
├───────────────────────────────────────┤
│                                       │
│ 技能文件: [ 选择文件 ]  (最大 50MB)   │
│                                       │
│ 来源类型: [ 开源 ▼ ]                  │
│           - 开源                      │
│           - ICSL                      │
│           - 华为                      │
│                                       │
│          [ 上传 ]  [ 取消 ]           │
└───────────────────────────────────────┘
```

6. 系统将自动解析 SKILL.md 中的元数据
7. 上传成功后，技能将进入"待审核"状态

#### 3.3 查看上传状态

1. 点击"我的技能"
2. 查看您上传的所有技能及其状态：

| 技能名称 | 版本 | 来源 | 上传时间 | 状态 | 操作 |
|---------|------|------|----------|------|------|
| Code Reviewer | 1.0.0 | 开源 | 2025-02-10 | ⏳ 待审核 | 详情 |
| Test Helper | 1.2.0 | ICSL | 2025-02-09 | ✅ 已批准 | 详情 |
| Old Skill | 0.9.0 | 开源 | 2025-02-01 | ❌ 已拒绝 | 详情 |

#### 3.4 状态说明

- **⏳ 待审核**: 技能已上传，等待管理员审核
- **✅ 已批准**: 技能通过审核，其他用户可见可下载
- **❌ 已拒绝**: 技能未通过审核，需要修改后重新上传
- **📤 已下架**: 技能已下架，其他用户无法看到

### 4. 管理我的技能

#### 4.1 我的技能页面

"我的技能"页面提供以下功能：

- **多选操作**: 使用复选框选择多个技能
- **全选功能**: 一键选择/取消所有技能
- **批量操作**: 批量下架、批量删除
- **单技能操作**: 下架、发布、设置默认版本、删除

**批量操作界面**:
```
┌─────────────────────────────────────────────────────┐
│ 我的技能                             [搜索框]        │
├─────────────────────────────────────────────────────┤
│ □ 全选                      [批量下架] [批量删除]    │
├─────────────────────────────────────────────────────┤
│ □ Code Reviewer v1.0.0  [下架] [设为默认] [删除]    │
│ □ Test Helper v1.2.0     [下架] [设为默认] [删除]    │
│ □ Security Scan v2.0.0   [下架] [设为默认] [删除]    │
└─────────────────────────────────────────────────────┘
```

#### 4.2 批量操作

**批量下架**:
1. 勾选要下架的技能
2. 点击"批量下架"按钮
3. 确认操作

**批量删除**:
1. 勾选要删除的技能
2. 点击"批量删除"按钮
3. 确认操作

⚠️ **注意**: 删除操作不可逆，请谨慎操作！

#### 4.3 设置默认版本

如果技能有多个版本，可以设置其中一个为默认版本：

1. 找到要设置的技能版本
2. 点击"设为默认"按钮
3. 该版本将作为首页显示的默认版本

#### 4.4 下架和发布技能

**下架技能**:
- 技能将从首页隐藏
- 已下载的用户仍可使用
- 可以随时重新发布

**发布技能**:
- 技能将重新显示在首页
- 其他用户可以下载

## 常见问题

### 用户常见问题

#### Q1: 忘记 API Key 怎么办？

**A**: 请联系管理员重置您的 API Key。管理员可以：
1. 在用户管理中找到您的账号
2. 点击"编辑"
3. 生成新的 API Key
4. 通过安全方式告知您

#### Q2: 为什么上传的技能一直显示"待审核"？

**A**: 这是正常现象。所有新上传的技能都需要管理员审核后才能发布。审核时间通常在 1-2 个工作日内。您可以：
- 在"我的技能"中查看状态
- 等待审核完成
- 查看通知获取审核结果

#### Q3: 技能被拒绝了怎么办？

**A**:
1. 查看拒绝原因（在"我的技能"中点击"详情"或查看通知）
2. 根据拒绝原因修改技能文件
3. 重新上传修改后的技能
4. 等待再次审核

#### Q4: 下载的技能如何安装？

**A**:
1. 解压下载的 ZIP 文件
2. 将技能文件复制到 Claude Code 技能目录：
   ```
   ~/.claude/skills/
   ```
3. 重启 Claude Code
4. 技能即可使用

#### Q5: 如何设置技能的默认版本？

**A**:
1. 进入"我的技能"页面
2. 找到要设置的版本
3. 点击"设为默认"按钮
4. 该版本将成为首页显示的默认版本

#### Q6: 批量操作有什么限制？

**A**:
- 批量删除需要技能处于非使用状态
- 批量操作无法撤销，请谨慎操作
- 一次最多可以选择 50 个技能进行批量操作

## 最佳实践

### 对于用户

#### 1. 技能命名规范

使用清晰、描述性的技能名称：
- ✅ 好的命名: `code-review-assistant`, `security-scanner`
- ❌ 不好的命名: `tool1`, `test`, `我的技能`

#### 2. 版本号管理

遵循语义化版本规范：
- 格式: `主版本.次版本.修订版本`
- 示例: `1.0.0`, `1.2.3`, `2.0.0`

#### 3. 编写清晰的 SKILL.md

在 SKILL.md 中详细描述：
- 使用 YAML frontmatter 格式
- 完整填写元数据字段（name, description, version, author 等）
- 技能的功能和用途
- 使用方法和示例
- 依赖和要求
- 已知限制

#### 4. 来源类型选择

正确选择技能来源：
- **开源**: 开源社区开发的技能
- **ICSL**: ICSL 内部开发的技能
- **华为**: 华为提供的技能

#### 5. 测试技能

在上传前充分测试：
- 在本地测试技能功能
- 验证 SKILL.md 格式正确
- 检查元数据完整
- 确认文件结构符合要求
