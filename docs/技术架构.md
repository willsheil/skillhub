# SkillHub 技术架构文档

## 1. 系统概述

SkillHub 是一个企业级 Claude Code 技能插件管理系统，提供完整的技能管理、审核、分发和 Git 集成功能。

### 1.1 核心特性

- **用户管理**: 基于工号和 API Key 的用户认证系统，支持用户和管理员角色
- **技能管理**: 支持多版本、多来源（opensource/icsl/huawei）的技能插件管理
- **审批流程**: 完整的技能审核和发布工作流，支持批量审核
- **统计分析**: 下载统计、用户活跃度分析、热门技能排行
- **Git 集成**: 异步推送已批准技能到 Gitea 仓库，支持并发处理
- **市场兼容**: 兼容 Claude Code 市场索引 API
- **通知系统**: 实时通知用户审核结果
- **批量操作**: 支持批量上传、下架、删除技能

### 4.5 Gitea 集成模块

#### 功能职责
- 异步推送已批准技能到 Gitea
- 并发任务处理（v2）
- 任务预留机制（行级锁）
- 重试逻辑（指数退避）
- 任务隔离（每个worker独立任务集）
- 健康监控和指标收集

#### 推送流程

```
┌──────────┐     批准      ┌──────────────────────────────────────┐
│ 技能审核 │ ────────────> │ 推送任务队列 (gitea_push_tasks)     │
└──────────┘               └──────────────────────────────────────┘
                              │
                              │ 后台服务（v2）
                              │ 并发workers
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                      Push Service v2                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │ Worker 1 │  │ Worker 2 │  │ Worker 3 │  │ Worker N │       │
│  └──────────┘  └──────────┘  └──────────┘  └──────────┘       │
│         │            │            │            │                │
│         └────────────┴────────────┴────────────┘                │
│                      │                                         │
│         任务预留（SELECT ... FOR UPDATE SKIP LOCKED）          │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                      Gitea Git Operations                       │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                     │
│  │ Clone    │  │ Add File │  │ Push     │                     │
│  └──────────┘  └──────────┘  └──────────┘                     │
└─────────────────────────────────────────────────────────────────┘
         │                              │
         │ 成功                         │ 失败
         ↓                              ↓
┌──────────────────┐          ┌──────────────────┐
│ status=success   │          │ 重试队列 (最多3次) │
│ 记录commit hash  │          └──────────────────┘
└──────────────────┘                    │
                                        ↓ 失败3次
                                 ┌──────────────────┐
                                 │ status=failed    │
                                 │ 记录error_message│
                                 └──────────────────┘
```

#### 任务状态机

```
┌──────────────┐
│   pending    │ 新创建的推送任务
└──────┬───────┘
       │
       ↓ worker预留任务
┌──────────────┐
│   reserved   │ worker已预留，开始处理
└──────┬───────┘
       │
       ↓ 开始推送
┌──────────────┐
│   pushing    │ 正在推送到Gitea
└──────┬───────┘
       │
       ├─────────────┐
       │ 成功        │ 失败（未达重试上限）
       ↓             ↓
┌──────────────┐ ┌──────────────────┐
│   success    │ │  retry_pending   │
└──────────────┘ └────────┬─────────┘
                         │ 重试
                         └──────────┐
                                    ↓ 失败次数>=max_retries
                         ┌──────────────────┐
                         │     failed       │
                         └──────────────────┘
```

#### 核心接口
```
GET  /api/gitea/status               # 推送服务状态
GET  /api/gitea/tasks               # 获取推送任务列表
POST /api/gitea/tasks/{id}/retry    # 手动重试任务
GET  /api/gitea/metrics             # 推送指标
GET  /api/gitea/alerts              # 推送告警
```

## 5. 数据库设计

### 5.1 数据库选择

系统使用 **MySQL 8.0+** 作为主数据库。

| 数据库 | 版本 | 用途 |
|--------|------|------|
| MySQL | 8.0+ | 主数据库 |

### 5.2 数据表结构

#### 用户表 (users)
```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    employee_id VARCHAR(20) UNIQUE NOT NULL,      -- 工号（格式：字母+8位数字）
    api_key VARCHAR(255) NOT NULL,                -- API密钥
    role VARCHAR(20) NOT NULL DEFAULT 'user',     -- 角色: user/admin
    status VARCHAR(20) DEFAULT 'active',          -- 状态: active/disabled
    skills_count INT DEFAULT 0,                   -- 技能数量
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_login TIMESTAMP NULL,
    KEY idx_users_employee_id (employee_id),
    KEY idx_users_role (role)
);
```

#### 技能表 (skills)
```sql
CREATE TABLE skills (
    id INT PRIMARY KEY AUTO_INCREMENT,
    skill_name VARCHAR(255) NOT NULL,             -- 技能名称
    version VARCHAR(50) NOT NULL,                 -- 版本号
    filename VARCHAR(255) NOT NULL,               -- 文件路径
    uploader_id INT NOT NULL,                     -- 上传者ID
    status VARCHAR(20) DEFAULT 'pending',         -- 状态: pending/approved/rejected
    source_type VARCHAR(20) DEFAULT 'opensource', -- 来源: opensource/icsl/huawei
    uploaded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    reviewed_at TIMESTAMP NULL,
    reviewer_id INT,
    review_comment VARCHAR(255),
    is_active TINYINT(1) DEFAULT 1,               -- 是否上架
    is_default_version TINYINT(1) DEFAULT 0,      -- 是否默认版本
    latest_push_task_id INT NULL,
    FOREIGN KEY (uploader_id) REFERENCES users(id),
    FOREIGN KEY (reviewer_id) REFERENCES users(id),
    FOREIGN KEY (latest_push_task_id) REFERENCES gitea_push_tasks(id),
    KEY idx_skills_status (status),
    KEY idx_skills_uploader (uploader_id),
    KEY idx_skills_name_version (skill_name, version),
    KEY idx_skills_active_default (skill_name, is_active, is_default_version)
);
```

#### 下载记录表 (downloads)
```sql
CREATE TABLE downloads (
    id INT PRIMARY KEY AUTO_INCREMENT,
    skill_name VARCHAR(255) NOT NULL,
    version VARCHAR(50) NOT NULL,
    filename VARCHAR(255) NOT NULL,
    downloaded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    ip_address VARCHAR(255),
    user_agent VARCHAR(255),
    user_id INT,
    FOREIGN KEY (user_id) REFERENCES users(id),
    KEY idx_downloads_skill (skill_name),
    KEY idx_downloads_user (user_id),
    KEY idx_downloads_time (downloaded_at)
);
```

#### Gitea 推送任务表 (gitea_push_tasks)
```sql
CREATE TABLE gitea_push_tasks (
    id INT PRIMARY KEY AUTO_INCREMENT,
    skill_id INT NOT NULL,
    skill_name VARCHAR(255) NOT NULL,
    version VARCHAR(50) NOT NULL,
    status ENUM('pending', 'reserved', 'pushing', 'success', 'failed', 'retry_pending') DEFAULT 'pending',
    retry_count INT DEFAULT 0,
    max_retries INT DEFAULT 3,
    error_message TEXT,
    commit_hash VARCHAR(40),
    gitea_path VARCHAR(500),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    reserved_at TIMESTAMP NULL,
    worker_id VARCHAR(50) NULL,
    started_at TIMESTAMP NULL,
    completed_at TIMESTAMP NULL,
    FOREIGN KEY (skill_id) REFERENCES skills(id),
    KEY idx_push_tasks_status (status),
    KEY idx_push_tasks_created (created_at),
    KEY idx_push_tasks_worker (worker_id, status)
);
```

#### 通知表 (notifications)
```sql
CREATE TABLE notifications (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    type VARCHAR(50) NOT NULL,                    -- 类型: approval/rejection/upload/system
    title VARCHAR(255) NOT NULL,
    content TEXT,
    related_skill_id INT,
    is_read TINYINT(1) DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (related_skill_id) REFERENCES skills(id),
    KEY idx_notifications_user_read (user_id, is_read),
    KEY idx_notifications_created (created_at)
);
```

## 7. 安全设计

### 7.1 认证机制

- **登录认证**: 工号 + API Key 双因子认证
- **会话管理**: 基于 Session 的会话管理
- **密钥存储**: API Key 使用安全存储
- **会话过期**: 可配置的会话超时时间

### 7.2 权限控制

| 角色 | 权限 |
|------|------|
| admin | 所有权限（审核、用户管理、统计、Gitea管理） |
| user | 上传技能、下载已批准技能、查看个人统计、管理自己的技能 |

### 7.3 安全建议

1. **生产环境部署**
   - 使用 HTTPS 协议
   - 配置防火墙规则
   - 定期更新依赖包
   - 启用日志审计

2. **数据安全**
   - 定期备份数据库
   - 敏感信息加密存储
   - 文件上传类型校验
   - 文件大小限制（50MB）

3. **API 安全**
   - 接口访问频率限制
   - SQL 注入防护（参数化查询）
   - XSS 攻击防护
   - CSRF 令牌验证

## 9. 部署架构

### 9.1 Docker Compose 部署

```yaml
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ${DB_PASSWORD}
      MYSQL_DATABASE: ${DB_DATABASE}
    volumes:
      - mysql_data:/var/lib/mysql
    restart: unless-stopped

  registry:
    build: .
    ports:
      - "28000:8000"
    volumes:
      - ./plugins:/app/plugins
      - ./pending:/app/pending
      - ./data:/app/data
    environment:
      - DB_HOST=mysql
      - DB_PORT=3306
    depends_on:
      - mysql
    restart: unless-stopped
```
