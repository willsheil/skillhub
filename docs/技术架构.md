# Claude Code Skill Registry 技术架构文档

## 1. 系统概述

Claude Code Skill Registry 是一个企业内部的技能插件管理系统，用于管理、审核和分发 Claude Code 技能插件。系统提供完整的用户认证、技能上传、审批流程、统计分析和 Git 集成功能。

### 1.1 核心特性

- **用户管理**: 基于工号和 API Key 的用户认证系统
- **技能管理**: 支持多版本、多组织的技能插件管理
- **审批流程**: 完整的技能审核和发布工作流
- **统计分析**: 下载统计、用户活跃度分析、热门技能排行
- **Git 集成**: 自动推送已批准技能到 Gitea 仓库
- **市场兼容**: 兼容 Claude Code 市场索引 API

## 5. 数据库设计

### 5.1 数据库选择

系统支持两种数据库：

| 数据库 | 适用场景 | 优势 |
|--------|----------|------|
| SQLite | 小规模部署、单实例 | 零配置、轻量级 |
| MySQL  | 中大规模、多实例 | 高性能、高并发 |

### 5.2 数据表结构

#### 用户表 (users)
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    employee_id TEXT UNIQUE NOT NULL,      -- 工号
    api_key TEXT NOT NULL,                 -- API密钥
    role TEXT NOT NULL DEFAULT 'user',     -- 角色
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_login TIMESTAMP
);

CREATE INDEX idx_users_employee_id ON users(employee_id);
CREATE INDEX idx_users_role ON users(role);
```

#### 技能表 (skills)
```sql
CREATE TABLE skills (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    skill_name TEXT NOT NULL,              -- 技能名称
    version TEXT NOT NULL,                 -- 版本号
    filename TEXT NOT NULL,                -- 文件路径
    uploader_id INTEGER NOT NULL,          -- 上传者ID
    status TEXT DEFAULT 'pending',         -- 状态
    uploaded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    reviewed_at TIMESTAMP,                 -- 审核时间
    reviewer_id INTEGER,                   -- 审核者ID
    review_comment TEXT,                   -- 审核意见
    FOREIGN KEY (uploader_id) REFERENCES users(id),
    FOREIGN KEY (reviewer_id) REFERENCES users(id)
);

CREATE INDEX idx_skills_status ON skills(status);
CREATE INDEX idx_skills_uploader ON skills(uploader_id);
CREATE INDEX idx_skills_name_version ON skills(skill_name, version);
```

#### 下载记录表 (downloads)
```sql
CREATE TABLE downloads (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    skill_id INTEGER NOT NULL,             -- 技能ID
    user_id INTEGER,                       -- 用户ID（可为空）
    download_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (skill_id) REFERENCES skills(id)
);

CREATE INDEX idx_downloads_skill ON downloads(skill_id);
CREATE INDEX idx_downloads_user ON downloads(user_id);
CREATE INDEX idx_downloads_time ON downloads(download_time);
```

### 5.3 数据库迁移

系统支持从 SQLite 迁移到 MySQL：

```python
# 迁移步骤
1. 配置 MySQL 连接参数（.env 文件）
2. 运行迁移脚本
3. 验证数据完整性
4. 切换应用数据库配置
```

## 6. API 设计




## 7. 安全设计

### 7.1 认证机制

- **登录认证**: 工号 + API Key 双因子认证
- **会话管理**: 基于 Session 的会话管理
- **密钥存储**: API Key 使用哈希存储
- **会话过期**: 可配置的会话超时时间

### 7.2 权限控制

| 角色 | 权限 |
|------|------|
| admin | 所有权限 |
| user | 上传技能、下载已批准技能、查看个人统计 |

### 7.3 安全建议

1. **生产环境部署**
   - 使用 HTTPS 协议
   - 配置防火墙规则
   - 定期更新依赖包
   - 启用日志审计

2. **数据安全**
   - 定期备份数据库
   - 敏感信息加密存储
   - 文件上传类型校验
   - 文件大小限制

3. **API 安全**
   - 接口访问频率限制
   - SQL 注入防护
   - XSS 攻击防护
   - CSRF 令牌验证
