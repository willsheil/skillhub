## 🚀 快速开始

### 1. 使用增强的日志系统

```python
from logging_config import setup_logging, audit_log, PerformanceTracker

# 初始化日志
logger = setup_logging(level="INFO")

# 基础日志
logger.info("操作成功", extra={"user_id": 123, "skill_name": "my-skill"})

# 审计日志
audit_log(logger, action="user_login", user_id=123, ip_address="192.168.1.1")

# 性能追踪
with PerformanceTracker(logger, "database_query"):
    result = db.execute("SELECT * FROM skills")
```

### 2. 启用优化的 Gitea 推送服务

```python
# main.py
@app.on_event("startup")
async def startup_event():
    if os.getenv("GITEA_REPO_URL"):
        from gitea_push_service_v2 import GiteaPushServiceV2

        push_service = GiteaPushServiceV2(
            interval=30,
            max_concurrent_tasks=3,
            retry_base_delay=1,
            retry_max_delay=300
        )

        asyncio.create_task(push_service.run())
```

### 3. 配置环境变量

```bash
# .env
LOG_LEVEL=INFO
LOG_DIR=./logs
LOG_MAX_BYTES=10485760
LOG_BACKUP_COUNT=5

GITEA_MAX_CONCURRENT_TASKS=3
GITEA_RETRY_BASE_DELAY=1
GITEA_RETRY_MAX_DELAY=300
GITEA_TASK_TIMEOUT=600
```

## 🔧 故障排查

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 推送任务堆积 | 检查 Gitea 服务器状态，调整并发数 |
| 日志文件过大 | 调整日志级别，启用轮转 |
| 性能下降 | 减少日志输出，调整并发任务数 |
| 推送失败率高 | 检查网络连接，查看错误日志 |

### 快速诊断命令

```bash
# 检查推送任务状态
curl http://localhost:8000/api/admin/gitea-tasks

# 查看错误日志
tail -f logs/error.log | jq '.'

# 检查健康状态
grep "Health check" logs/application.log | tail -1

# 查看推送成功率
grep "success_rate" logs/application.log | tail -1
```

## 🎯 核心改进点

### Gitea 推送优化

1. **并发处理** - 3倍性能提升（3个任务并发 vs 顺序处理）
2. **智能重试** - 指数退避算法，避免无效重试
3. **超时控制** - 防止任务永久挂起
4. **优先级队列** - 重要任务优先处理
5. **健康监控** - 实时指标和告警

### 日志系统增强

1. **结构化日志** - JSON 格式，易于解析和分析
2. **审计追踪** - 独立的审计日志，满足合规要求
3. **性能监控** - 自动追踪慢操作
4. **敏感信息保护** - 自动脱敏 API Key、Token 等
5. **日志轮转** - 自动归档，防止磁盘空间耗尽
