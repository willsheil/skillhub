# Gitea 推送优化和日志系统迁移指南

## 快速迁移检查清单

### 阶段 1: 准备阶段

- [ ] **备份现有系统**
  ```bash
  # 备份代码
  cp -r . ../registry-backup-$(date +%Y%m%d)

  # 备份数据库
  cp data/registry.db data/registry.db.backup

  # 备份配置
  cp .env .env.backup
  ```

- [ ] **检查当前运行状态**
  ```bash
  # 检查运行中的进程
  ps aux | grep uvicorn

  # 检查当前 Gitea 任务
  sqlite3 data/registry.db "SELECT * FROM gitea_push_tasks WHERE status='pending';"
  ```

- [ ] **记录当前配置**
  ```bash
  # 记录环境变量
  env | grep -E "(LOG_|GITEA_)" > current-config.txt

  # 记录日志配置
  python -c "import logging; print(logging.root.level)"
  ```

### 阶段 2: 实施阶段

- [ ] **添加新文件**
  - [ ] `logging_config.py` - 增强的日志配置
  - [ ] `gitea_push_service_v2.py` - 优化的推送服务
  - [ ] `logs/README.md` - 日志系统使用指南
  - [ ] `test_optimizations.py` - 测试脚本

- [ ] **更新配置文件**

  ```python
      level=os.getenv("LOG_LEVEL", "INFO"),

  # from gitea_push_service import GiteaPushService
  ```

## 回滚计划

如果新系统出现问题，按以下步骤回滚：

### 1. 快速回滚（代码层面）

```bash
# 1. 停止服务
sudo systemctl stop skill-registry

# 2. 恢复旧代码
cp ../registry-backup-YYYYMMDD/main.py ./main.py
rm gitea_push_service_v2.py logging_config.py

# 3. 重启服务
sudo systemctl start skill-registry
```

### 2. 完整回滚（包含数据）

```bash
# 1. 停止服务
sudo systemctl stop skill-registry

# 2. 恢复备份
cp -r ../registry-backup-YYYYMMDD/* .

# 3. 恢复数据库
cp data/registry.db.backup data/registry.db

# 4. 恢复配置
cp .env.backup .env

# 5. 重启服务
sudo systemctl start skill-registry
```

### 3. 回滚验证

```bash
# 检查服务状态
sudo systemctl status skill-registry

# 检查日志
tail -20 logs/application.log
```

## 常见问题和解决方案

### 问题 1: 导入错误

**错误信息**:
```
ImportError: cannot import name 'setup_logging' from 'logging_config'
```

**解决方案**:
```bash
# 确认文件存在
ls -la logging_config.py

# 检查 Python 路径
python -c "import sys; print(sys.path)"

# 重新安装依赖
pip install -r requirements.txt
```

### 问题 2: 日志文件权限

**错误信息**:
```
PermissionError: [Errno 13] Permission denied: './logs/application.log'
```

**解决方案**:
```bash
# 创建日志目录并设置权限
sudo mkdir -p /var/log/skill-registry
sudo chown $USER:$USER /var/log/skill-registry
chmod 755 /var/log/skill-registry

# 或者使用本地目录
mkdir -p logs
chmod 755 logs
```

### 问题 3: Gitea 推送服务未启动

**错误信息**:
```
Failed to start Gitea push service: 'GiteaPushServiceV2'
```

**解决方案**:
```bash
# 检查环境变量
env | grep GITEA

# 验证 Gitea 配置
python -c "from gitea_client import GiteaClient; c = GiteaClient()"

# 检查数据库表
sqlite3 data/registry.db ".schema gitea_push_tasks"
```

### 问题 4: 日志文件过大

**错误信息**:
```
磁盘空间不足
```

**解决方案**:
```bash
# 1. 立即清理旧日志
rm logs/application.log.*

# 2. 调整日志级别
# 在 .env 中设置
LOG_LEVEL=WARNING

# 3. 减小日志文件大小
# 在代码中设置
max_bytes=5*1024*1024  # 5MB

# 4. 启用日志压缩
# 配置 logrotate
```

### 问题 5: 性能下降

**错误信息**:
```
应用响应变慢
```

**解决方案**:
```bash
# 1. 检查日志 I/O
iotop -o

# 2. 调整日志级别
LOG_LEVEL=ERROR

# 3. 使用异步日志
# 在 logging_config.py 中启用 QueueHandler

# 4. 减少并发推送任务
GITEA_MAX_CONCURRENT_TASKS=1
```
